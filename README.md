# Tag Tracker — website / landing page

Marketing landing page for the [Tag Tracker](https://github.com/Shekh-Muhsen/tag-tracker) app.
Static HTML/CSS (no build). Hosted via GitHub Pages.

- **App source:** https://github.com/Shekh-Muhsen/tag-tracker
- **Download (APK folder):** the OneDrive link in `index.html` (updated from time to time).

To edit, change `index.html`. To publish, enable **Settings → Pages → Deploy from branch: main /(root)**.
